# Day 9 – Log Enrichment System

## Overview

This project implements a basic SOC-style Log Enrichment System using Python.

The system takes raw security logs and adds contextual information such as geographical location, device type, and severity. The enriched data is stored in structured JSON format for further security analysis.

## Objectives

* Understand log enrichment in a SOC environment
* Map raw security events to meaningful context
* Add geographical information to IP addresses
* Identify device types where available
* Classify events by severity
* Generate structured enriched logs

## Enrichment Pipeline

```text
Raw Logs
   ↓
IP Validation
   ↓
GeoIP Lookup
   ↓
Device Information
   ↓
Severity Classification
   ↓
Enriched JSON
```

## Project Structure

## Technologies Used

* Python 3
* JSON
* `ipaddress` module
* Rule-based event classification

## Enrichment Fields

The system adds:

* Country
* Region
* Device Type
* Severity

Severity levels:

* **Low** – Normal or low-risk activity
* **Medium** – Suspicious activity requiring investigation
* **High** – Potentially serious malicious activity

## How to Run

```bash
python3 log_enrichment.py
```

## GeoIP Implementation

For this learning project, a local demonstration GeoIP mapping is used instead of a live GeoIP service.

The mapping provides approximate country and region information for selected IP addresses.

In a production SOC environment, a trusted and regularly updated GeoIP database or service would be used.

## Limitations

* The GeoIP data is a mock/local dataset.
* Device type depends on information available in the original log.
* Severity classification is rule-based.
* The system does not determine whether an IP is actually malicious.

## Security Relevance

Log enrichment helps SOC analysts understand security events by adding contextual information to raw logs. This can improve alert triage, investigation, correlation, and prioritization.

The enriched logs generated by this module can later be used as input for the Week 2 risk-scoring and anomaly-detection modules.

## Learning Outcome

Learned how raw security logs can be enriched with contextual information such as geographical location, device type, and severity to support SOC analysis and threat detection.
